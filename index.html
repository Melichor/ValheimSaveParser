Valheim Achievement Hunter

Drop in a character file and see what each achievement still needs from you.

Your file is analysed in this tab by the real achi_hunter.py script and is never uploaded.

Where is my character file?

Local saves (Steam Cloud off) are in a characters_local folder:

Windows: %USERPROFILE%\AppData\LocalLow\IronGate\Valheim\characters_local
Linux: ~/.config/unity3d/IronGate/Valheim/characters_local

Steam Cloud saves are kept by Steam, not in the game's own folder:

<Steam folder>/userdata/<your Steam ID number>/892970/remote/characters

  • Steam folder: C:\Program Files (x86)\Steam on Windows; ~/.steam/steam or ~/.local/share/Steam on Linux and Steam Deck (Debian may use ~/.steam/debian-installation).
  • Steam ID number: the numeric folder inside userdata. If there are several, take the most recently modified one.
  • Shortcut: in Steam, right-click Valheim → Manage → Browse local files, then go up three folders to the Steam folder.
  • Tip: once you are in the userdata folder, search it for your character's name or for 892970. That finds the right folder and file straight away.

The file is named after your character, e.g. Ragnar.fch. Ignore the .fch.old and _backup_ copies; use the plain .fch file.

Upgrade name finder

Upgrading at the upgrade station is a dice roll that, for a new character, is decided by the character's name. Enter an item and the quality it starts at, and this finds names of new characters that give 8 upgrades in a row. It runs upgrade_oracle.py in your browser and needs no save file.

  • Upgrades wanted is how many upgrades the item you keep should get, counted from the starting quality. A single copy can never get more than 8 in a row, two copies at most 13 and three at most 18, so asking for more needs more copies. Names for the highest values are extremely rare.
  • Copies is how many items of this kind you are willing to use, all starting at the quality above. Every copy but the last is a sacrifice: upgrade it, step by step, until it breaks. Each attempt moves the character's stored rolls on, which sets up the rolls the last copy, the one you keep, goes through. Its upgrades are the number you asked for, and then you stop.
  • Each name comes with its upgrade path: for every copy, the steps to take in order and what each roll does. Do the copies in the order listed, all with the same new character.
  • The more upgrades and the fewer copies, the rarer the names: searching can take a few minutes and may find nothing. Using more copies makes high targets possible, but every extra copy is another item that breaks.

    Before you create the character

    • The case of the name is saved. The game keeps the name exactly as you type it, with its upper and lower case letters, even when the name box or the game shows it in capitals. FazI and fazi are different names with different rolls, so type it exactly as listed. (Only the file name is lowercase.)
    • Make every upgrade with a character that has exactly that name. Create a new character with the name and do all of the listed upgrades with it, in the order listed. Each roll comes from the name of the character making that upgrade, so an upgrade made by any other character is a different roll and is not covered by this list. (The one exception you may want is the last upgrade, see "Crafted by" below.)
    • The name only works for the first item of this kind that character upgrades. Once it has made an upgrade, the game stores a random roll for that item and level, so a second copy of the same item won't follow this list. This is for Valheim 1.0.20.
    • Use an item that has not been upgraded at the upgrade station yet. If it was upgraded before the update, enter the level it has now. If it has already been upgraded on this update, this finder won't work for it. (This page is based on Valheim 1.0.20.)
    • Unlock the item's recipe on the new character first. A new character does not know the item's base recipe yet. You need to encounter the workbench (crafting station) the item is crafted at, and register every item that is required to craft it, before you can upgrade the item with that character.
    • Stop after the last upgrade listed. In the default mode that is the 8th, and a 9th attempt would break the item. In advanced mode the copy you keep is simply left alone after its last listed upgrade.
    • Want your own "Crafted by:" name? The item shows the character that made its last upgrade. If you want a custom text there, keep the last upgrade for a character with that name, as that is the one that gets saved on the item. That last roll then comes from that character's own name, so it is not covered by this list and can fail.
    • The names are only valid for the starting quality you entered. A different starting quality needs different names.
