Valheim Achievement Hunter

Upload a character file and see what each achievement still needs from you.

Your file is analysed in this tab by the real achi_hunter.py script and is never uploaded.

Where is my character file?

Windows: %USERPROFILE%\AppData\LocalLow\IronGate\Valheim\characters_local

Linux: ~/.config/unity3d/IronGate/Valheim/characters_local

Characters stored with Steam Cloud are in a folder named characters next to it. The file is named after your character, e.g. Ragnar.fch.

Built from the game's own achievement rules (Valheim 1.0.16). Source and command-line version on GitHub. Not affiliated with Iron Gate.
