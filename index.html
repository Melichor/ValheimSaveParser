Valheim Achievement Hunter

Drop in a character file and see what each achievement still needs from you.

Your file is analysed in this tab by the real achi_hunter.py script and is never uploaded.

Where is my character file?

Local saves (Steam Cloud off) are in a characters_local folder:

Windows: %USERPROFILE%\AppData\LocalLow\IronGate\Valheim\characters_local
Linux: ~/.config/unity3d/IronGate/Valheim/characters_local

Steam Cloud saves are kept by Steam, not in the game's own folder:

<Steam folder>/userdata/<your Steam ID number>/892970/remote/characters

  • Steam folder: C:\Program Files (x86)\Steam on Windows; ~/.steam/steam or ~/.local/share/Steam on Linux and Steam Deck (Debian may use ~/.steam/debian-installation).
  • Steam ID number: the numeric folder inside userdata. If there are several, take the most recently modified one.
  • Shortcut: in Steam, right-click Valheim → Manage → Browse local files, then go up three folders to the Steam folder.
  • Tip: once you are in the userdata folder, search it for your character's name or for 892970. That finds the right folder and file straight away.

The file is named after your character, e.g. Ragnar.fch. Ignore the .fch.old and _backup_ copies; use the plain .fch file.

Upgrade name finder

Every upgrade at the Forge of Potential is a dice roll, and the roll comes from the character that makes it: for a new character, from its name. Enter an item and the quality it starts at, and this finds names of new characters that give 8 upgrades in a row, the most one character can get. To go further, the relay planner below finds a chain of characters that pass the item along. It runs upgrade_oracle.py in your browser and needs no save file.

    Relay planner: more than 8 upgrades

    A chain of new characters can take an item as far as you want without breaking it: each one makes only the upgrades its own rolls get right, then hands the item to the next. Enter the item, its current quality and the quality you want.

      Before you create the characters

      • The case of the name is saved. The game keeps the name exactly as you type it, with its upper and lower case letters, even when the name box or the game shows it in capitals. FazI and fazi are different names with different rolls, so type it exactly as listed. (Only the file name is lowercase.)
      • Every upgrade must be made by the character listed for it. Each roll comes from the character making that upgrade, so an upgrade made by anyone else is a different roll that the list does not cover. With a relay plan, go in order: each character makes only its own listed upgrades, puts the item in a chest, and the next character takes it out and continues.
      • Use new characters. A name only works for the first item of this kind that character upgrades: once it has made an upgrade, the game stores a different roll for that item and level, so a second copy of the same item won't follow the list. The characters must never have upgraded this item type at the Forge of Potential before.
      • Unlock the item's recipe on each new character first. A new character does not know the item's base recipe yet. It needs to encounter the workbench (crafting station) the item is crafted at and register every item that is required to craft it. Bring the materials for its upgrades too.
      • Use an item that has not been upgraded at the Forge of Potential yet. If it was upgraded before the update, enter the level it has now. If it has already been upgraded on this update, this won't work for it. (This page is based on Valheim 1.0.20.)
      • Stop after the last upgrade listed. With a name from the finder that is the 8th, and a 9th attempt would break the item. In a relay plan, each character stops after its own levels.
      • Want your own "Crafted by:" name? The item shows the character that made its last upgrade, so in a relay plan that is the last character in the list. For a custom name, let a character with that name make the last upgrade. That roll comes from that character's name, not from the list, so check it first: in the Upgrade predictor below, enter the item, the quality it has before that upgrade, and the custom name. If its first step works, the upgrade is safe. If it would break, stop a level or more earlier and check the custom name from there instead. This assumes a new character with that name, one that has not upgraded this item type at the Forge of Potential yet.
      • Each roll belongs to a level, not to the starting quality. A name found for, say, quality 3 to 11 also works for any part of that range, such as 6 to 11, because the rolls for levels 7 to 11 are the same ones. Starting below the quality you searched for is not covered: those lower levels were never checked.

      Upgrade predictor

      Drop a character file to see, for every upgradable item in its inventory, how many upgrades it can take at the Forge of Potential before it breaks. It runs upgrade_oracle.py in your browser and the file is never uploaded.

      Or predict a single item without a file, as a new character with the name you enter. A new character has no saved seeds, so every roll comes from the name.

      • The item must not have been upgraded at the Forge of Potential before.
      • The character must not have upgraded this item type at the Forge of Potential before, with any copy of it. If it has, drop its character file above instead: that uses the rolls stored in the file.

        How to read it

        • The roll for an upgrade comes from the character's name the first time it upgrades that item to that level, and from a stored seed in the file after that. The prediction uses whichever the file says applies, so it is exact for the next attempts of this character.
        • Each item is predicted as if it were the first of its kind you upgrade. With two copies of the same item, the second one continues from the seeds the first leaves behind, so its path differs.
        • An attempt that is not a success breaks the item, so each path ends with a break. You can stop before it: the path shows how far you would get.
